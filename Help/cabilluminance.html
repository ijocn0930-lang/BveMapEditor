BVE Map Editor エラー解説: 運転台の明るさ（CabIlluminance）

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 原因

CabIlluminance.Interpolate(値) は運転台の明るさ（0〜1）を距離程ごとに決め、その間をなめらかにつなぎます。近い距離程で値を大きく変えると、つなぐ途中で 0 より小さく、または 1 より大きくなり（オーバーシュート）、表示がおかしくなることがあります。

  • 同一または極めて近い距離程で値が急変している … 距離程の間が短すぎます。
  • 変化率が大きすぎる … 距離に対して値の変化が大きすぎます。
  • 引数には 0 以上 1 以下の値を指定してください

🛠️ 直し方

間違い（トンネルの入口で 0.5m しか離れていない）

1000; CabIlluminance.Interpolate(1); 1000.5; CabIlluminance.Interpolate(0.3);

正しい（距離をあけて少しずつ変える）

1000; CabIlluminance.Interpolate(1); 1020; CabIlluminance.Interpolate(0.3);

✨ 修正の候補

距離程や値をどうするかを決める必要があるため、修正の候補はありません。手で直してください。
