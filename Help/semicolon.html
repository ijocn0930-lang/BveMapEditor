BVE Map Editor エラー解説: セミコロン ;

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 原因

マップファイルでは、1つの文（コマンドや距離程）の終わりに必ず ;（セミコロン）を書きます。

  • 文の終わりにセミコロン ';' がありません … 文の最後の ; が抜けています。1行に2つの文を書いて、間の ; が抜けている場合もこのエラーになります。
  • セミコロン ';' が複数連続して記述されています … ;; のように ; が続いています（動きには影響しませんが、書き間違いの可能性があります）。

※ 文字列の閉じる ' が抜けていると、; まで文字列の中と読まれて「; 抜け」になることがあります。その場合は ' を足してください。

🛠️ 直し方

間違い

Curve.Begin(300, 0.105) Repeater['FenceR'].End() Structure['CrossSig'].Put0('0', 0, 1); Curve.End();;

正しい

Curve.Begin(300, 0.105); Repeater['FenceR'].End(); Structure['CrossSig'].Put0('0', 0, 1); Curve.End();

+ や , で終わる行は、次の行に続く1つの文として読みます（その行には ; は不要です）。

✨ 修正の候補

エラー一覧またはエディタの行を右クリック ➔「修正の候補」で直せます。「文の終わりに ; を付ける」「連続した ; を1つにする」。同じファイルに何件もあるときは「まとめて直す」も使えます。
