BVE Map Editor エラー解説: Load 系コマンド・リストファイル

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 原因

Structure.Load / Station.Load / Signal.Load / Sound.Load / Sound3D.Load は、マップで使うリストファイル（CSV）を読み込みます。ファイルの上の方（最初の距離程より前）に書きます。

  • 必須の 'X.Load' が見つかりません … そのリストを読み込む行がありません。
  • Load系コマンドは、距離程よりも前のファイル上部に配置してください … Load が距離程の後ろに書かれています。
  • Load系コマンドの引数はアポストロフィで囲む / 片方しかありません / ファイルパスが指定されていません … ファイル名の書き方が間違っています。
  • 指定されたファイルが見つかりません / リストファイルが見つかりません … ファイル名か、フォルダの場所が違います。パスはこのマップファイルのあるフォルダから数えます（..\ は1つ上のフォルダ）。
  • リストファイルのヘッダーが無効です … CSV の1行目が「BveTs Structure List 2.00」などで始まっていません。
  • 同じ Load 定義が重複して記述されています … 同じ Load を2回書いています。

🛠️ 直し方

正しい書き方の例

BveTs Map 2.02:utf-8 Structure.Load('Structures.csv'); Signal.Load('Signals.csv'); Sound.Load('Sounds.csv'); Sound3D.Load('Sounds3D.csv'); Station.Load('Stations.csv'); 0;

※ Sound.Load は Station.Load より前に書いてください。

✨ 修正の候補

「必須の 'X.Load' が見つかりません」は、右クリック ➔「修正の候補」で Load の行を足せます（ほかの Load の行の下に入り、カーソルが '' の間に来るので、ファイル名を入力してください）。
