BVE Map Editor エラー解説: 曲線・カント・勾配（BeginTransition / SetGauge）

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 原因

  • 'BeginTransition' is required before 'Begin' / 'End' … Curve・Gradient・Track['…'].Cant の Begin / End の前に、緩和区間の始まり BeginTransition がありません。BeginTransition の距離程から Begin（End）の距離程までが緩和区間になります。
  • BeginTransition(); を2か所連続して配置できません … BeginTransition の後に Begin / End がないまま、もう一度 BeginTransition を書いています。
  • Curve.SetGauge が設定される前にカント付きの Curve 操作が行われています … カントを付ける前に、軌間を Curve.SetGauge（または Curve.Gauge）で設定してください。
  • Track['X'].Cant.SetGauge(); が設定される前にカント操作が行われています … 他軌道のカントの前に、Track['X'].Cant.SetGauge（または Track['X'].Gauge）で軌間を設定してください。

🛠️ 直し方

正しい書き方の例

0; Curve.SetGauge(1.067); 1000; Curve.BeginTransition(); 1050; Curve.Begin(400, 0.105); 1300; Curve.BeginTransition(); 1350; Curve.End();

軌間は狭軌なら 1.067、標準軌なら 1.435 です。

✨ 修正の候補

右クリック ➔「修正の候補」で次の直し方を選べます。
  • BeginTransition がない → ダイアログで距離程を選び、その距離程の行のすぐ下に BeginTransition の行を足す
  • SetGauge がない → エラーの行の上に SetGauge の行を足す（1.067 / 1.435 から選ぶ）
