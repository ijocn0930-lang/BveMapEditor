BVE Map Editor エラー解説: 引数（( ) の中の値）

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 原因

  • X の引数は N 個である必要があります（現在: M個） … ( ) の中の値の数が合っていません。よくあるのは Put（9個）と Put0（3個）の取り違えです。
  • X の第 N 引数には数値を指定してください … 数値の位置に文字や名前が入っています。
  • X の第 N 引数は文字列のため ' ' で囲む必要があります … 軌道名やストラクチャーキーなどの文字列を ' ' で囲んでいません（distance もここではただの文字として扱われます）。
  • 0 または 1 / 0 以上 1 以下 / 傾斜オプション 0〜3 … 決まった範囲の値を指定してください（傾斜オプションは 0〜3 の外（4 以上・マイナス）でも何も出しません。BVE は 2 進数の下 2 けた（0: 水平・1: 勾配・2: カント・3: 両方）で動きます）。
  • .X() の引数には何も指定できません … ( ) の中を空にします。
コマンド引数
Structure['キー'].Put軌道名, x, y, z, rx, ry, rz, 傾斜, スパン（9個）
Structure['キー'].Put0軌道名, 傾斜, スパン（3個）

🛠️ 直し方

間違い

Structure['abc'].Put('0', 1, 25); Structure['abc'].Put(xyz, 0, 0, 0, 0, 0, 0, 0, 0); Structure['abc'].Put0('0, 1, 25);

正しい

Structure['abc'].Put0('0', 1, 25); Structure['abc'].Put('xyz', 0, 0, 0, 0, 0, 0, 0, 0); Structure['abc'].Put0('0', 1, 25);

✨ 修正の候補

右クリック ➔「修正の候補」で、次の直し方を選べます。
  • 引数の数が合うコマンドに変える（Put ↔ Put0、Begin ↔ Begin0）
  • 足りない引数を後ろに足す（数値は 0、文字列は ''）／多い引数を後ろから消す（Repeater は除く）
  • 文字列の閉じる ' を足す、名前を ' ' で囲む
