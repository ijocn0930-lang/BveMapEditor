BVE Map Editor エラー解説: 未知のコマンド・書き方の間違い

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 原因

  • 未知のコマンドまたは存在しない単語です … BVE にないコマンド名です。つづり（例: Structre / Curve.Begn）、. の抜け（例: Structure['a']Put）、名前の間の空白（例: Structure['a'] Put0）を確認してください。
  • 'X' の後にドット '.' が抜けているか、コマンドの記述形式が不正です … 例: StructureLoad( は Structure.Load( です。
  • その名前 '$X' は存在しません … 変数を使う前に $X = …; で値を入れていないか、変数名のつづりが違います（変数は include の順番にも注意）。
  • Invalid character … 使えない記号が入っています。

コマンド名の大文字・小文字は区別しません。

🛠️ 直し方

間違い

Structre['a'].Put0('0', 0, 25); Structure['CrossSig']Put0('0', 0, 1); Curve.Begn(300, 0.105);

正しい

Structure['a'].Put0('0', 0, 25); Structure['CrossSig'].Put0('0', 0, 1); Curve.Begin(300, 0.105);

コマンド名は、入力中に出る自動補完の候補から選ぶと間違いを防げます。

✨ 修正の候補

右クリック ➔「修正の候補」で、つづりの近いコマンド名・名前（include や名前空間）を最大3つ出します。( ) の中の引数の数が合うコマンドだけを出します（例: 引数3個なら Put0）。. の抜けも直せます。
