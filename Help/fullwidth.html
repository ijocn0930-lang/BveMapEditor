BVE Map Editor エラー解説: 全角文字

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 原因

コマンド・数値・記号は半角で書きます。全角の英数字・記号（（ ） ； ０〜９ Ａ〜Ｚ など）が入っているとエラーになります。全角スペースだけのときは何も出しません（BVE5・BVE6 ではエラーにならないため）。

日本語は、' ' で囲んだ文字列の中と、# や // の後ろのコメントなら書けます。

続いている全角文字は、まとめて1件のエラーになります。

🛠️ 直し方

間違い

Curve.Begin（３００，　0.105）；

正しい

Curve.Begin(300, 0.105); # 曲線（コメントの日本語は OK）

✨ 修正の候補

右クリック ➔「修正の候補」で、続いている全角文字をまとめて半角にできます（例: 「（３００）」→「(300)」）。ひらがな・漢字など半角にできない文字が混じっているときは、候補は出ません。同じファイルに何件もあるときは「まとめて直す」も使えます。
