BVE Map Editor エラー解説: 括弧 ( ) [ ]

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 原因

コマンドの引数は丸括弧 ( )、キーは角括弧 [ ] で囲みます。開いた括弧と閉じた括弧の数が合っていないとエラーになります。

  • 閉じ括弧 ')' / ']' が不足しています … 閉じる括弧が足りません。
  • 対応する '(' / '[' がない閉じ括弧が存在します … 閉じる括弧が多すぎます。
  • コマンドの後に丸括弧 '()' がありません … 引数がないコマンドでも ( ) は必要です。
  • 括弧が演算子なしで連続して記述されています / 演算子不足または予期せぬ括弧の記述があります … 式の中で ( ) と ( ) の間や、数値と ( の間に + などの演算子が抜けています。

🛠️ 直し方

間違い

Curve.Begin(300, 0.105; Track['A'].Cant.SetGauge; Curve.Begin((300)(2));

正しい

Curve.Begin(300, 0.105); Track['A'].Cant.SetGauge(1.067); Curve.Begin((300) * (2));

✨ 修正の候補

「コマンドの後に丸括弧 '()' がありません」は、右クリック ➔「修正の候補」➔「コマンドの後に () を付ける」で直せます。括弧の数が合わないものは、どこが正しいかを判断できないため、手で直してください。
