BVE Map Editor エラー解説: キー ['…']

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 原因

Structure・Sound・Sound3D・Station・Signal・Track・Repeater・Train などのコマンドは、Structure['キー'] のように角括弧と引用符でキー（名前）を指定します。キーはリストファイル（Structure.Load などで読み込む CSV）に書かれている名前と同じでなければなりません。

  • キー 'X' は対応するリストファイルに存在しません … リストファイルにその名前がありません（つづり・大文字小文字の違い・リストへの書き忘れ）。
  • リストがまだロードされていないため、キー 'X' を検証できません … そのリストを読み込む .Load がない、またはこの行より後ろにあります。
  • 角括弧 '[]' が不足 / '[]' の中にキーが指定されていません / キーはアポストロフィ等で囲む … キーの書き方が間違っています。
  • 指定には丸括弧 '()' ではなく、角括弧 '[]' を使用してください … キーを ( ) で書いています。
  • Repeater のストラクチャキー … Repeater の Begin（11 番目以降）/ Begin0（5 番目以降）の引数に書いたストラクチャーのキーがリストにありません。
  • ステーションキー 'X' が重複して記述されています … 同じ駅を2回配置しています。

🛠️ 直し方

間違い

Structure.Put('0', 0, 0, 0, 0, 0, 0, 0, 25); Structure[Bg_Fine].Put('0', 0, 0, 0, 0, 0, 0, 0, 25); Structure['Bg_Fnie'].Put('0', 0, 0, 0, 0, 0, 0, 0, 25);

正しい

Structure['Bg_Fine'].Put('0', 0, 0, 0, 0, 0, 0, 0, 25);

キーの候補は、Structure[' と入力すると自動補完で一覧に出ます（構文チェックが一度終わった後）。

✨ 修正の候補

「リストファイルに存在しません」は、右クリック ➔「修正の候補」で、つづりの近いキーを最大3つ出します（例: Bg_Fnie → Bg_Fine）。「アポストロフィが片方しかありません」「アポストロフィ等で囲むか…」は「キーを ' ' で囲む」で直せます（例: [FormR0] → ['FormR0']）。
