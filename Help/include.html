BVE Map Editor エラー解説: include

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 原因

include 'ファイル名.txt'; は、別のマップファイルをその位置に読み込みます。ファイル名は ' ' で囲み、このファイルのあるフォルダから数えたパスで書きます。

  • 'include' の引数はアポストロフィ等で囲む必要があります … ' ' がない、または閉じる ' が抜けています。
  • 'include' の引数にファイルパスが指定されていません / 不要な '=' が含まれています … 書き方が間違っています。
  • 'include' で指定できるファイルは拡張子が '.txt' のファイルのみです
  • インクルード先のファイルが見つかりません … ファイル名か場所が違います。
  • 循環インクルード（無限ループ）が検出されました … A が B を include し、B が A を include しているなど、読み込みが輪になっています。

インクルード先のエラーは、エラー一覧の「ファイル名」にそのファイルが表示されます。ダブルクリックでそのファイルを開けます。

🛠️ 直し方

間違い

includ 'Track_define.txt'; include 'Map_RunIndexDefine_E217r.txt; include = 'Track_define.txt';

正しい

include 'Track_define.txt'; include 'Map_RunIndexDefine_E217r.txt';

✨ 修正の候補

右クリック ➔「修正の候補」で、閉じる ' の足し忘れ（「閉じる ' を足す」）や、includ → include のようなつづりの間違いを直せます。
