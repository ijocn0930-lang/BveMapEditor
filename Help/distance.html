BVE Map Editor エラー解説: 距離程・計算式

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 原因

距離程は 1320; や 1320 + $WK02;、distance + 25;（直前の距離程 + 25）のように、数値・変数・計算式に ; を付けて書きます。

  • 距離程は 0 以上の実数である必要があります … 計算した結果がマイナスです。
  • 距離程にカンマを付けることはできません … 1,320 のように , を入れています。
  • 距離程の式が演算子 '+' で終わっています … + の後ろが抜けています。
  • Cannot convert literal … to type Int32 / 算術計算でオーバーフロー … 数値が大きすぎます。
  • distance変数には数値を代入してください / 右辺と左辺を逆に書くことはできません … 変数の代入の書き方が間違っています（$変数 = 値; の形）。
  • 数式の計算に失敗しました … 計算式を読めませんでした。括弧や演算子を確認してください。

distance は、距離程の行の中でだけ「今の距離程」になります。コマンドの引数に書くとただの文字として扱われます。

🛠️ 直し方

間違い

1,320; distance +; 100 - 200;

正しい

1320; distance + 25; $KM = 100; $KM + 200;

✨ 修正の候補

「距離程の式が演算子 '+' で終わっています」は、右クリック ➔「修正の候補」➔「最後の演算子 + を消す」で直せます。
