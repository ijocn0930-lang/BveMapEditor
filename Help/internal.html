BVE Map Editor 解説: 構文チェックそのもののエラー

ファイル: __FILE__

発生位置: 行 __LINE__

メッセージ: __MSG__

🔍 内容

マップの書き方ではなく、構文チェックをする部分（BveMapParserWorker）でうまく処理できなかったことを表します。

  • パーサー内部でエラーが発生しました / 意味解析中に予期せぬ例外が発生しました … チェックの処理で想定外のことが起きました。エディタの不具合の可能性があります。
  • ワーカーとの通信に失敗しました … 構文チェックの別プロセスと通信できませんでした。少し待つか、エディタを起動し直してください。
  • 構文チェックが時間内（60 秒）に終わらなかったため、ワーカーを起動し直しました … 構文チェックの別プロセスが固まったため、自動で起動し直しました。マップを書き換えると、もう一度チェックします。何度も出るときは開発者に知らせてください。
  • ファイルが空です … ファイルに何も書かれていません。
  • ファイルが大きすぎる / リクエストデータが大きすぎる … チェックできる大きさ（約 2,000 万文字）を超えています。

🛠️ 対処

「パーサー内部でエラー」が出たときは、エラー一覧の行を右クリック ➔「行のコピー」で内容をコピーし、そのとき開いていたマップの行と一緒に開発者に知らせてください。原因を調べるのに役立ちます。
