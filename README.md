# BVE Map Editor

BVE Trainsim 5 / 6 向けのBVE Map構文（`BveTs Map 2.02`）専用・高機能テキストエディタです。
リアルタイム構文エラーチェック、自動補完（IntelliSense）、BVE直連デバッグ機能、大規模ファイル対応（AvalonEdit）を備え、安全かつ快適なマップ制作環境を提供します。

---

## 🌟 主な特徴

- **高性能なコードエディタ（AvalonEdit）**
  - 数十万行クラスの大規模マップファイル（67万文字等）でも軽量・軽快に動作（行の仮想化表示）。
  - BVE Map構文に特化したカスタムシンタックスハイライト（コメント、数値、文字列、キーワードの色分け）。
- **リアルタイム構文エラー検出（別プロセス解析）**
  - 入力に追従してバックグラウンドで構文解析（`BveMapParserWorker`）を実行。UIスレッドをフリーズさせません。
  - 下部の「構文エラー一覧」ダブルクリックで該当行・列へ即座にカーソルジャンプ。
  - エラーコンテキストメニューから行コピー、Web検索、Gemini相談をサポート。
- **高度なBVE構文検証（`MapParser`）**
  - ヘッダー検証（`BveTs Map 2.02`）、重複ヘッダー検出。
  - 必須構文（`Station.Load`等）の記述順序・距離程（`0;`）前後の配置チェック。
  - 括弧の不整合（`()`, `[]`）、引用符抜け、文末セミコロン忘れ、全角・マルチバイト文字混入検出。
  - 各種参照CSVリスト（ストラクチャー・サウンド・ステーション）のキー存在照合。
  - 変数（`$変数名`）構文対応および各種誤用判定（`$`抜け、複数代入、引数内代入など）。
- **インテリジェントな自動補完（IntelliSense）**
  - BVE構文コマンドやパラメータの入力補完（`BveSyntaxProvider`）。
  - スペースキー・数値入力時の誤発火防止ガード。
- **デバッグ & ツール連携**
  - エディタ内からBVE5/6本体およびQuickMapViewerを直接起動・デバッグ走行。
  - 実行ファイルパスの自動保存・オープンダイアログでのフォールバック。
- **プロジェクト & ワークスペース管理**
  - エクスプローラーペイン（ファイルツリー）と複数タブ編集。
  - エクスプローラーペイン設定ファイル（`.bveep`）の保存・復元・OS関連付け。
  - クラッシュ時の作業自動復元機能およびタブ・ペイン状態の保存。

## 💻 動作環境

- **OS**: Windows 10 / 11 (64-bit)
- **開発環境 / フレームワーク**: C# (WPF) / .NET 10.0 (.NET 8.0 以降対応)
- **対応ファイル形式**: BVE Trainsim 5 / 6 Map ファイル (`BveTs Map 2.02`)

---

## 🚀 使い方

1. **ファイル・フォルダを開く**
   - メニューの `ファイル` ➔ `ファイルを開く` または `フォルダを開く` からプロジェクトを選択します。
2. **マップ編集 & エラー確認**
   - コード編集時、画面下部の「構文エラー一覧」に検出されたエラーがリアルタイム表示されます。
   - エラー項目をダブルクリックすると、該当する行・列へ直接ジャンプします。
3. **BVEでデバッグ実行**
   - メニューの `デバッグ` ➔ `BVEでデバッグ実行` を選択すると、編集中のマップをBVE本体で直接テスト走行できます（初回の実行ファイル指定ダイアログで `.exe` を登録）。

## 🛠 プロジェクト構成

```
BveMapEditor/
├── BveMapEditor/             # WPFメインアプリケーション
│   ├── MainWindow.xaml       # 主画面レイアウト（3分割・タブ・エラー一覧）
│   ├── MainWindow.xaml.cs       # メインクラス
│   ├── MapParser.cs          # 構文解析インターフェース
│   ├── MapHighlighter.cs     # AvalonEditハイライト制御 (BveMap.xshd)
│   ├── BveSyntaxProvider.cs  # 自動補完・キーワード定義
│   └── AppSettings.cs        # 設定保持 (settings.json)
└── BveMapParserWorker/       # 構文チェック用別プロセス（コンソールアプリ）
    ├── Program.cs            # Named Pipe 通信サーバー
    ├── BveLexer.cs           # 字句解析・トークナイザ
    ├── BveParser.cs           # パーサー
    ├── BveSemanticAnalyzer.cs # 構文処理
    ├── BveSyntaxProvider.cs  # 自動補完・キーワード定義
    └── MapParser.cs           # パーサー

```
